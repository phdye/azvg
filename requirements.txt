# AZVG Requirements for Python 3.2.5
# 
# This project uses ONLY the Python 3.2.5 standard library.
# No external dependencies are allowed due to target environment constraints.
#
# External dependencies replaced with standard library:
# - click -> argparse (built-in)
# - pyyaml -> json (built-in) 
# - requests -> urllib2 (built-in)
# - colorama -> (not needed)
# - python-dateutil -> datetime (built-in)
# - tabulate -> custom simple_table function
#
# To install azvg:
#   python setup.py install
#
# For development:
#   python setup.py develop
#   # OR add src/ to PYTHONPATH
